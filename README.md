Automated System Health Monitor

Overview :

Automated System Health Monitor is a Python-based project that monitors system performance in real time. It tracks CPU usage, memory usage, and disk usage, and displays alerts when system resources exceed predefined limits

Features :
1.Monitor CPU usage

2.Monitor Memory usage

3.Monitor Disk usage

4.Real-time monitoring

5.Threshold-based alerts

5.Simple and lightweight Python implementation

Technologies Used

Python

psutil library
